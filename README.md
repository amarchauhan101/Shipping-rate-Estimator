# Shipping Estimator

This is a project I built while learning C# and.NET with a React frontend.

You enter the parcel details Shipping Estimator shows the price from 3 carriers. You can save

a quote and then book the Shipping Estimator quote, dispatch Shipping Estimator or mark Shipping Estimator delivered.

There is no database. Everything is stored in a list in memory. The Shipping Estimator data is

gone when I stop the backend.

## Tech used

- Backend: C#.NET 8 Web API

- Frontend:. Vite

## How to run

You need the.NET SDK and Node.js installed.

Backend (runs on http://localhost:5080):

cd backend

dotnet run

Frontend (open a terminal):

cd frontend

npm install

npm run dev

Then open http://localhost:5173 in the browser.
